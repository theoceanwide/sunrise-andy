4-week sprint

Week 1
Microsoft 365 Setup
  • Create Teams channels: Ops, Nursing, Kitchen, Transport, Activities, Admin
  • Migrate Google Drive → SharePoint (compliance, SOPs, forms folders)
  • Set up compliance folder structure (CDPHE, HHSC, Licensing, Incident Reports)
  • Invite all staff to Teams + confirm login for each
  • Connect check-in app (checkin.sunriseseniordaycare.com) to SharePoint list
Week 2
KPI Dashboard v1
  • Export sample data from myadultdaycare.com (attendance, cost, transport)
  • Build Power BI report: Occupancy %, Cost per Client-Day, Labor %, Transport Utilization, Referral Conversion
  • Write DAX measures (use Claude prompt below for code)
  • Share dashboard with Joe for review + feedback
  • Set up Power Automate: daily KPI email to leadership at 7am
Week 3
SOP Documentation
  • SOP #1: Seizure protocol on transport vehicle (priority)
  • SOP #2: Fall incident response — in facility + on bus
  • SOP #3: Client intake & onboarding
  • SOP #4: Daily program schedule + Club Hour
  • SOP #5–10: Kitchen HACCP log, medication administration, elopement, driver checklist, referral intake, billing cycle
Week 4
Power Apps Prototypes
  • Build Power App: Bus driver check-in + incident log form → syncs to SharePoint
  • Build Power App: Kitchen inventory daily count form
  • Build Viva Engage training module (use existing PRD + program schedule as content)
  • Competitive research deck: top 5 ADC operators in Denver + Houston markets
  • Present sprint results to Joe + Grace — demo dashboard live
